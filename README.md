# Vennie Ruz Barola — Professional Portfolio

A personal portfolio for Vennie Ruz Barola, highlighting executive assistance, B2B lead generation, appointment setting, customer support, research, and administrative operations.

## Built with

Vite 6, React 19, TypeScript, CSS custom properties, Three.js, GSAP, Lenis, React Router 7, Phosphor icons, and Poppins.

## Run locally

```bash
npm install
npm run dev
npm run build
npm run lint
```

## Portfolio content

- **Home:** Professional introduction, experience statistics, and navigation.
- **Experience:** Employment history and responsibilities.
- **Capabilities:** Executive/admin support, lead generation, customer support, government opportunity research, and CRM coordination.
- **Career Highlights:** Resume-backed workload figures.
- **Working Style:** Communication, follow-through, organization, and adaptability.
- **About:** Professional background and education.
- **Contact:** Email-based inquiry form.
